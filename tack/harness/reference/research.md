# Research — 外部资料调研

针对当前代码库之外的事实性问题，启动一个**后台 agent** 调研可信一手来源，你继续手头工作。

## 与 code-explorer 的分工

- `harness/agents/code-explorer.md`：对**本仓库代码**做只读事实勘探（入口、调用链、数据流）
- 本文件：答案在**仓库之外**——官方文档、语言/框架规范、第一方 API 文档、第三方依赖源代码；仓库整体结构分析走 `ask`，不用本流程

## 研究任务

1. 只针对**可信的一手来源**调查，不采用二手综述；追溯每个声明回拥有它的源头
2. 将结果写成一份带来源的 Markdown 文件，每个关键声明附出处链接或文档位置
3. 保存边界遵守 `harness/rule/record-wiki.md`：稳定导航锚点与代码外事实经人工审阅后沉淀到 `$root/wiki/`；易变或仅本次有效的资料留在 `$work/wiki/`，不写入根 wiki

## 输出

- 问题与结论（每条标注来源）
- 来源清单与可信度说明；一手来源之间矛盾时保留分歧，不擅自取舍
- 对当前 plan / 编码决策的影响（如涉及选型或用法约定，交回主流程由用户确认）
