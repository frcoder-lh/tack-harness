# run 指令索引

> 本文件是 `run/` 目录的指令索引，只负责**识别、索引与编排**，不记录具体执行细节。
> 每条 run 指令的步骤、脚本清单与凭据要求记录在 `run/<指令>/run.md`。
>
> 目录约定：
> - `run/<指令>/`：该指令的全部脚本与数据
> - `run/<指令>/local/`：**敏感数据目录（已被 .gitignore 忽略，不入版本库）**——该指令的密钥、token、账号、环境变量等一律放在这里，脚本从该目录读取

## 指令索引

| 指令 | 目录 | 触发词 | 用途 | 依赖 |
|------|------|--------|------|------|
|      | `<指令>/` |    |      |      |

## 识别规则

- 用户输入命中指令名、触发词或用途 → 执行该指令
- 命中多条或无法识别 → 列出本索引请用户选择，不臆造指令
- 用户指定多个指令时，按「依赖」列排序执行

## 编排规则

- 执行前逐条读取 `<指令>/run.md`，并执行 `run-plan.sh check run/<指令>` 校验其机器可读清单
- 按「依赖」列的先后执行；无依赖关系时保持用户指定顺序
- `requires` 列出的必需文件（通常为 `<指令>/local/` 下的凭据）缺失时提示用户补充，不继续执行
- 任一指令失败即停止后续指令并报告；需要人工介入的步骤等待用户确认
- 执行结果（输出、日志）写入 `<指令>/local/` 或控制台，不回写本索引

## 新增指令

1. 新建 `run/<指令>/` 与其 `local/`
2. 按 `harness/template/run-instruction.md` 生成 `run/<指令>/run.md`，脚本与数据放入该目录
3. 在本文件「指令索引」表登记指令名、目录、触发词、用途与依赖
