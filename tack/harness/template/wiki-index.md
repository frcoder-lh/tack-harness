# <project> 项目 wiki 索引

> 本索引只做导航：说明每个分类记录什么、具体问题去哪个分类索引或文件查询。
> 路径相对本文件；分类目录按需创建，未创建的分类暂无内容。写入与索引更新规则见 `harness/rule/wiki-write.md`，读取规则见 `harness/rule/wiki-read.md`。

## 分类索引

| 分类 | 收录内容 | 索引 |
|------|----------|------|
| biz 业务理解 | 业务线概述与长期背景、术语定义与边界、业务领域职责与不变量、来源资料 | `biz/index.md` |
| code 代码理解 | 仓库概览、业务术语 → 代码入口、接口 → 业务场景、长期保留的分析 | `code/index.md` |
| rule 项目规则 | 项目级技术决策（ADR）、工程约定与偏好 | `rule/index.md` |
| config 项目配置 | 服务清单与职责、环境与泳道、网关地址、租户与账号、关键配置、中间件事实 | `config/index.md` |
| history 历史归档 | 已关闭工作区的 `summary.md` 与移入的 `run/` | `history/index.md` |

## 分类说明

- **biz**：回答「业务是什么、术语什么意思、边界在哪」。
- **code**：回答「这个术语/接口对应哪段代码、仓库怎么组织」；易变调用链留在工作区 `$work/doc/analysis/` 与 `story/<story>/analysis.md`。
- **rule**：回答「为什么这样定、开发时必须遵守哪些代码外约定」。
- **config**：回答「服务部署在哪、地址/泳道/账号/配置怎么查」。
- **history**：回答「过去某个需求为什么做、是否设计如此」。

新增分类时在本表登记并创建对应 `<分类>/index.md`。
