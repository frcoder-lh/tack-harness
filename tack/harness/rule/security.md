# 安全编码与审查规则

> 被 `code`（编码时加载）、`agents/code-reviewer.md`（「约定与安全」视角）与 `run` / `test`（凭据落位）引用。
> 定位：高频、可机械识别的安全模式清单。每条给出**危险模式 → 风险 → 正确做法**。
> 语言/框架的具体安全基线由项目自行补充到本文件（优先融合，不重复造文件）。

## 输入与命令执行

- **命令注入**：把外部输入拼进 shell 命令字符串（`os.system`/`Runtime.exec`/`subprocess(shell=True)`/反引号等）
  - 风险：任意命令执行
  - 做法：参数数组形式调用（不经 shell 解释）；必须拼命令时用白名单校验/转义；禁止用 `shell=True` 跑含输入的命令
- **代码注入**：`eval`/`Function`/动态编译加载执行外部可控内容
  - 做法：禁止对外部输入使用动态执行；表达式需求用安全解析器或白名单映射
- **路径穿越**：外部输入直接拼接文件路径（`open(base + name)`、解压/下载文件名）
  - 风险：任意文件读写、zip slip
  - 做法：路径规范化后校验仍位于允许目录内；拒绝 `..`、绝对路径、UNC 路径；解压逐个校验条目路径

## 数据与查询

- **SQL 注入**：字符串拼接 SQL（含 `${}` 直拼、ORDER BY/LIMIT 等参数化覆盖不到的位置）
  - 做法：一律参数化/预编译；表名/排序字段用白名单映射； like 通配符与引号显式转义
- **危险反序列化**：pickle/marshal、Java 原生序列化、fastjson autoType、XML 外部实体（XXE）等反序列化不可信数据
  - 做法：禁用或开启白名单/类型限制；XML 关闭外部实体与 DTD；优先 JSON 等安全格式
- **NoSQL/模板/LDAP 注入**：查询对象与模板表达式中混入外部输入（Mongo `$where`、SSTI 等）
  - 做法：参数化查询 API；模板与外部数据严格分离

## Web 边界

- **XSS**：未转义内容写入 HTML（`innerHTML`、`v-html`、未编码的模板输出、富文本未过滤）
  - 做法：默认上下文转义；富文本用白名单消毒库；设置 CSP 纵深防御
- **SSRF**：服务端按外部输入发起请求（webhook、图片抓取、URL 预览）
  - 做法：URL scheme/host 白名单；解析并校验目标 IP（拒绝内网、环回、链路本地、元数据地址）；跟随跳转后重新校验
- **越权（IDOR/缺鉴权）**：按请求里的 id/租户参数取数据而不校验归属；新接口漏挂鉴权中间件
  - 做法：服务端从会话取主体并强制归属/权限校验；默认拒绝，显式放行；对象级权限逐接口验证
- **CSRF/开放重定向**：状态变更接口无 CSRF 防护；重定向地址取自外部输入
  - 做法：SameSite+token 校验；重定向目标白名单

## 凭据、加密与配置

- **硬编码密钥**：代码/配置/日志中出现密码、token、私钥、内部地址凭据
  - 做法：走密钥管理/环境注入；日志与异常脱敏；提交前自查 diff；密钥一经泄露必须轮换
- **弱加密**：MD5/SHA1 用于安全目的、明文或可逆方式存密码、硬编码密钥与固定 IV、自造加密
- **做法**：密码用 bcrypt/scrypt/Argon2；传输与敏感存储用标准 AEAD（AES-GCM 等）且随机 IV；随机数用 CSPRNG
- **敏感信息泄漏**：堆栈/调试信息/接口报错直接返回前端，错误日志带身份证、手机号、银行卡
  - 做法：对外通用错误信息，细节只进受控日志并脱敏；生产关闭调试模式与目录列举

## 工作区凭据落位

- 运行时凭据（密钥、token、账号、环境变量）一律写入 `$work/run/local/`（如 `local/credentials.sh`、`local/.env`），该目录已被 `.gitignore` 全局忽略、不入库；脚本从该目录读取，禁止硬编码
- 入库文档（`test.md` 测试方案等）只标注凭据来源（`run/local/<文件>`），不写明文

## 依赖与供应链

- 引入新依赖前确认来源可信、维护活跃、无已知高危漏洞；锁定版本与锁文件
- 不执行来源不明的安装脚本（postinstall 等）与 curl | sh；插件/上传文件不得被当作代码执行

## 使用要求

- 编码时：命中以上模式即按正确做法实现，并在自测中覆盖一条恶意输入用例
- 审查时：发现命中按 Critical/Warning 分级报告，必须附 `文件:行号` 与具体利用方式；不确定可利用性的降级为 Warning 并说明前提
