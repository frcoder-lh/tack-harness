# 沉淀 agents（AGENTS.md 常驻约定）规则

> 被 `record` 命令引用：类型判定为 agents 时，按本文件落盘。

## 落点

- `$root/AGENTS.md` 的「## 沉淀约定」区块（该区块位于「## 项目信息」之前，由 record 维护）

## 区块不存在时

- 在「## 项目信息」标题行之前插入区块（含固定说明行，模板见下），再追加条目

## 条目格式

- 每条一行，带日期与可执行的明确表述，如：

  ```
  - **2026-09-25** Windows 下执行 harness 脚本统一走 run.ps1（-ExecutionPolicy Bypass），路径参数用正斜杠
  ```

- 已表达相同约束的条目：就地更新（替换表述、必要时追加日期），**不重复新增**
- 内容本质是对「tack harness 核心约束」的补充、且用户明确要求入列时：追加为核心约束的新编号条目；否则一律进「沉淀约定」区块
- 模板预置的「本区块尚无条目……」引导行在追加首条时删除

## 边界（禁止项）

- 不得修改 `<!-- tack:info:start -->` 与 `<!-- tack:info:end -->` 之间由 project.sh 维护的 YAML 区块
- 不得改动区块标记、环境变量与目录概览等 harness 固定章节

## 区块模板

```markdown
## 沉淀约定

> 由 `/tack record` 沉淀的项目级常驻约定，人工审阅后生效；更新时优先与已有条目融合，不重复追加。
> 项目信息 YAML 区块由 project.sh 维护，请勿手改。

- **<日期>** <一条明确、可执行的约定>
```

## 生效

- 展示落盘内容，**必须经人工审阅确认后才可作为上下文**
